# رِواق ERP — Rewaq Multi-Branch Showroom & Interior Ecosystem

> **المنظومة السحابية المتكاملة لإدارة معارض وصالات الأثاث، الديكور والإضاءة مع المتاجر الإلكترونية وربط إعلانات Meta والضرائب المصرية**

---

## 🌟 نظرة عامة (Overview)
**رِواق ERP** هو حل سحابي متطور مصمم خصيصاً لتلبية احتياجات شركات وتجارة الأثاث والديكور في الشرق الأوسط ومصر. يدمج النظام بين:
1. **لوحة تحكم مركزية (ERP & CRM):** المبيعات، العقود، المخازن المتعددة، المشتريات، الشحن واللوجستيات، المالية والمحاسبة، وشؤون الموظفين والرواتب.
2. **3 قوالب مواقع إلكترونية متخصصة:**
   - معرض الأثاث المنزلي والمودرن (`/furniture`)
   - معرض الإضاءة والتحف الذكية (`/lighting`)
   - استوديو التشطيبات والتصميم الداخلي الفاخر (`/luxury-studio`)
3. **تكامل كامل مع منظومة الفاتورة الإلكترونية المصرية (ETA) وضريبة القيمة المضافة 14%.**
4. **تتبع مبيعات الصالة الناتجة عن إعلانات Meta و Conversions API (ROAS).**

---

## 🚀 التقنيات المستخدمة (Tech Stack)
- **Framework:** Next.js 15 (App Router) & React 19
- **Styling:** Tailwind CSS & Lucide Icons & Radix UI
- **Typography:** Cairo Arabic Typography
- **Language:** TypeScript
- **Architecture:** Multi-Branch & Multi-Warehouse Architecture

## 💻 التشغيل والتثبيت (Getting Started)

### 1. تثبيت الحزم (Install Dependencies)
```bash
npm install
```

### 2. تشغيل السيرفر المحلي (Development Server)
```bash
npm run dev
```

افتح المتصفح على [http://localhost:3000](http://localhost:3000) للوصول إلى صفحة تسجيل الدخول ومنظومة رِواق ERP.

### 3. بناء نسخة الإنتاج (Production Build)
```bash
npm run build
npm run start
```
